# CPPractice Lab

A simple, attractive C++ practice website built with HTML, CSS, and JavaScript.

## Features
- 💻 Solve problems in your own IDE (VS Code, Code::Blocks, etc.)
- 📚 1200+ problems across 12 sections
- 🏆 Track your progress (Mark as Solved)
- 📱 Mobile friendly
- 🌓 Dark mode support
- 🚀 No installation required
- 🔍 Click any problem to view full statement + example input/output
