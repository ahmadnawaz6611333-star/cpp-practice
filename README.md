# CPPractice Lab

A simple, attractive C++ practice website built with HTML, CSS, and JavaScript.

## Features
- 💻 Solve problems in your own IDE (VS Code, Code::Blocks, etc.)
- 📚 1200+ problems across 12 sections
- 🏆 Track your progress (Mark as Solved)
- 📱 Mobile friendly
- 🌓 Dark mode support
- 🚀 No installation required
- 🔍 Click any problem to view full statement + example input/output

## How to Use Locally

1. Open `index.html` in any web browser
2. Browse problems by category
3. Click any problem to see the full statement and example
4. Open your IDE and write your C++ code
5. Test with the sample input/output shown
6. Mark the problem as solved when complete

## How to Host Online (Free)

### Option 1: GitHub Pages
1. Create a GitHub repository
2. Upload all files (`index.html`, `style.css`, `script.js`)
3. Go to Settings → Pages
4. Select source branch and click Save
5. Your site will be live at `https://yourusername.github.io/repo-name/`

### Option 2: Netlify
1. Go to netlify.com
2. Drag and drop the `cpp-practice-website` folder
3. Your site is live instantly!

### Option 3: Vercel
1. Go to vercel.com
2. Connect your GitHub repository
3. Deploy automatically on every push
